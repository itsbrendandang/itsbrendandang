## Kalos

[![CI](https://github.com/itsbrendandang/kalos-engine/actions/workflows/ci.yml/badge.svg)](https://github.com/itsbrendandang/kalos-engine/actions/workflows/ci.yml)

[kalos-engine](https://github.com/itsbrendandang/kalos-engine) is an open-source Bayesian-optimization engine for bioprocess experiment campaigns, served as an HTTP API.
Upload a run sheet, get an analysis and a proposed next batch, and run the propose-measure-re-propose loop.
The proof is [BENCHMARK.md](https://github.com/itsbrendandang/kalos-engine/blob/main/BENCHMARK.md): the optimizer beats a Latin Hypercube design on synthetic surfaces when noise is low.
A win on real data is not yet claimed.

[kalos-web](https://github.com/itsbrendandang/kalos-web) is the scientist-facing UI for the campaign loop: Setup, Plan, Run, Record, Learn.
